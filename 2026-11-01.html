Google Jules 종료… 실질 마감은 11월 11일
Google (10월 29일 공지) · The Verge · TestingCatalog

Google이 비동기 AI 코딩 에이전트 Jules를 종료한다. 헤드라인 날짜는 12월 31일이지만, 실질 마감은 11월 11일이다. 그날 이후 Jules는 읽기 전용이 돼 세션을 이어갈 수 없다. 2024년 12월 실험으로 시작한 Jules는 GitHub 저장소에 연결해 버그 수정·의존성 업데이트·테스트 작성을 백그라운드에서 처리하는 모델이었다. Google은 기술적·보안적 문제가 아니라, 에이전트 코딩 역량을 Antigravity 하나로 통합하기 위한 결정이라고 한다.

사용자 할 일은 명확하다. 11월 11일 전에 진행 중 세션을 마치고, 설정·환경변수·예약 작업·저장소·메모리·설정 스크립트·전체 세션 기록을 로컬 폴더로 내보낼 것. 마감 시각이 공지되지 않았으니 11월 10일을 개인 마감으로 잡는 게 안전하다. 같은 날 Antigravity 플러그인 마켓플레이스가 열렸다. 스킬·MCP 서버·규칙·훅·커스텀 에이전트를 한 번의 클릭으로 설치하는 디렉토리로, Stripe·Vercel·Notion·Linear·Supabase·Zapier 등이 초기 라인업이다. Antigravity 빌드에서는 Jules의 핵심이던 클라우드 실행을 암시하는 로컬/클라우드 전환 토글과 Running Jobs 섹션이 포착됐지만, 출시 일정은 미확정이다. 무료 티어의 하루 15개 작업·동시 3슬롯에 대응하는 조건도 아직 발표되지 않았다.

Claude Code 2.1.316… 서브에이전트 노력도 설정
Anthropic (10월 31일) · Claude Code 릴리스 노트

Claude Code 2.1.316이 나왔다. 핵심은 세 가지다. 첫째, CLAUDE_CODE_SUBAGENT_EFFORT로 서브에이전트의 노력 수준을 세션 상속이 아니라 직접 지정할 수 있게 됐다. 둘째, CLAUDE_CODE_DISABLE_ULTRATHINK로 ultrathink 키워드를 끌 수 있다. 참고로 ultrathink는 이제 사고 예산 힌트가 아니라 턴 전체를 xhigh 노력도로 돌리는 선택자다. 셋째, Opus 4.8 fast mode가 10월 30일부로 폐기됐고 11월 30일에 제거된다. 제거 후 fast mode 요청은 에러를 반환하고 표준 모드로 폴백되지 않으니, fast mode를 고정한 스크립트나 관리 설정은 Opus 5.5로 옮겨야 한다.

버전 번호의 뒷이야기도 있다. 변경 로그는 2.1.312 다음 2.1.314, 2.1.316 순으로 이어지는데, 2.1.313은 지난주 Cursor 마켓플레이스 변조 확장이 사칭한 번호라 실제 릴리스 트레인에서 건너뛰었다. 그 밖에 --restricted 세션의 작업 디렉토리 밖 파일 업로드, 종료 시 셸 명령 잔존, 서브에이전트의 모델 이동 같은 수정이 포함됐다.

🔧 하네스 관점
네 듀얼 리뷰어 설계에 직접 닿는 변경이다. ui/code 리뷰어를 서브에이전트로 돌릴 때 노력도를 세션 상속이 아니라 역할별로 고정할 수 있게 됐다는 뜻이다. 예를 들어 ui 리뷰어는 중간, code 리뷰어는 높음 식으로. 반대로 fast mode 제거처럼 "느려지는 게 아니라 에러가 되는" 변경은 하네스의 모델 고정을 주기적으로 점검해야 하는 이유를 보여준다. 네 하네스의 모델 기본값도 Opus 5.5 계열로 정리된 상태인지 확인해 볼 만하다.

볼 포인트 ─ 11월 30일 fast mode 제거 후 에러 보고, 서브에이전트 노력도 설정의 실측 효과.

Factory Droid 1.0… 도구 호출을 코드로 묶다
Factory AI (10월 30~31일) · MarkTechPost

Factory AI가 코딩 에이전트 하네스 Droid 1.0을 내놨다. 핵심은 프로그램 방식 도구 호출이다. 모델이 도구 호출을 하나씩 쏘고 결과를 기다리는 대신, 샌드박스에서 도는 JavaScript 프로그램을 짜서 수백 개의 도구 호출을 한 번의 모델 요청으로 실행한다. 기본 프롬프트는 20,887토큰에서 13,055토큰으로 37% 줄었고, 미리 실리는 도구 정의도 11개에서 2개로 줄었다. 새로 발견한 도구를 요청에 추가하는 방식도 바꿔, 일반 프로덕션 요청의 입력 중 98%를 프롬프트 캐시에서 읽는다고 한다.

벤치마크는 자사 발표 기준이다. Terminal-Bench 4에서 Opus 5.5 기준 65.2%, 통과 태스크당 $4.73로, 같은 모델의 Codex·Claude Code·Cursor·Devin·OpenCode를 앞섰다고 한다. GPT-6.1 Sol 기준으로는 Codex보다 3.5~3.6%p 높고 비용은 12% 낮다. macOS·Windows 데스크톱 앱과 터미널 UI, Node SDK(@factory/droid-sdk)로 제공되고, 유료 플랜은 월 $20부터다. 독립 검증 전이라는 점은 감안해야 한다.

올트먼 방한… 삼성 사장단 50명·최태원 오찬
삼성·SK (10월 31일) · MTN · 뉴시스

샘 올트먼 OpenAI CEO가 1박 2일 방한 일정으로 삼성 사장단과 최태원 SK그룹 회장을 잇따라 만났다. 삼성은 10월 31일 용인 삼성인력개발원에서 전자·금융·바이오 등 주요 관계사 사장단 50여 명과 'AI가 바꿀 다음 10년, 기업의 선택'을 주제로 간담회를 열었다. 삼성은 지난 6월부터 전사 AX를 추진 중이고, 사장단부터 임원 약 2,300명 교육을 거쳐 내년 2월까지 전 임직원 AI 교육을 마칠 계획이다. 올트먼은 이 자리에서 사장단에게 '코덱스 마이크로 키보드'를 선물했다.

같은 날 최태원 회장과의 오찬도 있었다. SK하이닉스 등 주요 계열사 임원들이 참석했고, 대화 내용은 공개되지 않았지만 HBM 공급과 AI 데이터센터 구축 등 기존 협력이 중심이었을 것으로 보인다. 양측은 지난해 10월 메모리 공급 의향서(LOI)와 서남권 AI 데이터센터 MOU를 맺고 스타게이트에 협력 중이고, 삼성도 같은 시기 LOI를 맺었다. 이재용 회장은 지난 7월 오픈AI 본사를 방문한 바 있다. Anthropic IPO를 앞둔 시점의 행보라는 점도 맥락이다.
