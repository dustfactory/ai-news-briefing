Mistral Large 4 'Le Chonk' 오픈 웨이트 공개
Mistral AI (10월 29일) · Unite.AI · TestingCatalog

Mistral이 1조 파라미터급 플래그십 Mistral Large 4의 가중치를 공개했다. 10월 6일 API 프리뷰 이후 3주간의 추가 강화학습을 거쳐 코딩과 방어적 사이버 보안에서 큰 폭의 향상을 이뤘다고 한다. 네이티브 멀티모달 MoE로, 토큰당 활성 파라미터는 약 52B, 컨텍스트는 1M 토큰이다.

벤치마크는 자사 발표 기준이다. FrontierCode 2.0에서 19.7%로 오픈 웨이트 1위, Coding Agent Index 48%로 GLM-5.3과 동점이면서 태스크당 토큰은 47% 적게 쓰고, Terminal-Bench 4.0은 프리뷰 28%에서 41%로 올랐다. 사이버 인덱스 51%, 악성 사이버 요청 거부율 평균 96.6%도 내세웠다. 독립 검증은 아직 전이다. 라이선스는 수정 MIT로, 상용·파인튜닝은 자유지만 Model-as-a-Service 재판매는 별도 라이선스가 필요하다. API 가격은 입력 $0.70/캐시 $0.07/출력 $2.10 per 1M 토큰, NVFP4 양자화 버전은 B200·B300 4장으로 돌릴 수 있다고 한다.

LangChain, 에이전트에 브라우저를 달다
LangChain (10월 29일) · Superpower Daily

LangChain이 Managed Deep Agents v0.10을 공개 베타로 내놨다. 핵심은 두 가지다. 첫째, 브라우저 사용 기능. API가 없는 사이트의 예약·폼 확인 같은 일을 에이전트가 직접 클릭해서 처리한다. define_browser(scope="thread", idle_ttl_seconds=600) 한 줄로 선언하면 snapshot·run·screenshot·handoff 네 가지 도구가 자동 추가된다. 브라우저는 LangSmith 샌드박스에서 원격으로 돌고, 스레드마다 별도라 쿠키·로그인이 섞이지 않는다.

둘째, 비동기 서브에이전트와 사람 인계(handoff)다. 로그인 벽이나 2차 인증에 막히면 에이전트가 browser_handoff(reason)를 호출하고, 사람은 링크로 원격 브라우저를 열어 직접 로그인한 뒤 제어권을 돌려준다. 비밀번호는 모델 메시지·트레이스에 남지 않고, 링크는 15분 만료다. API가 있으면 API를 쓰라는 게 LangChain의 권고다. 브라우저는 API의 빈틈을 메우는 용도다.

🔧 하네스 관점
네 하네스의 ui_reviewer 규칙 14("바뀐 UI를 직접 조작해 전후 이미지로 증명")와 같은 맥락이다. 브라우저 도구를 리뷰어의 증거 수단으로 붙일 때, LangChain의 패턴이 참고된다. 스레드별 격리 브라우저, 스냅샷 ID 기반 조작, 사람 인계 시 비밀번호 비노출 원칙이 그대로 적용 가능하다. 단, 리뷰어는 로그인 인계가 아니라 읽기 전용 세션을 기본으로 해야 한다.

Hermit… 모델도 하네스도 얼리고 어댑터만 학습
Infini-AI-Lab v0.1.0 (10월 25일) · MarkTechPost

Infini-AI-Lab이 오픈소스 하네스 어댑터 프레임워크 Hermit v0.1.0을 냈다. 아이디어가 선명하다. 모델도, 하네스도 건드리지 않고, 바깥에 붙는 '하네스 어댑터'만 학습시켜 Codex나 Claude Code를 새 태스크에 맞춘다. 파인튜닝도, 하네스 포크도 필요 없다. Python 프레임워크로 자체 파라미터는 없고, Apache-2.0에 pip install hermit-harness로 설치한다.

학습은 RL식 루프다. 트레이너가 현재 어댑터를 단 에이전트로 태스크 배치를 돌리고, 저지가 채점해 어댑터를 진화시킨다. 진화 방법 5종이 내장됐다. GEPA·SkillOpt·MetaWorld Model(MWM)·Harness²·Continual Harness. GLM 5.3 Flash 기준 CL-Bench 데이터베이스 탐색에서 MWM 어댑터가 0.795로, 인컨텍스트 베이스라인 0.580을 크게 앞섰다. 단, 대부분 단일 자가 보고 실행이라 반복 검증이 필요하다. 백엔드는 API 일체와 로컬 vLLM·SGLang·Ollama를 지원한다.

OpenAI Model Spec, 다섯 가지 가치로 재편
OpenAI (10월 29일) · Reuters · Unite.AI

OpenAI가 Model Spec을 개정했다. 모델이 어떻게 행동해야 하는지를 설명하는 공개 문서가 이제 다섯 가지 가치 중심으로 재편됐다. 인간 의도에 대한 충실성, 위해 최소화, 정직과 투명성, 인간 주체성 촉진, 배려다. 토대는 '인간 의도에 대한 충실성'으로, 지시를 글자대로 따르는 게 아니라 사용자와 개발자, OpenAI가 의도하고 가치 있게 여기는 바를 이해하라는 뜻이다.

실무적으로 중요한 변화도 있다. 상세한 스타일 지침 대부분이 은퇴했고, 맥락·감독·주체성에 대한 새 지침과 일부 행동 기본값 조정이 들어갔다. 지시 충돌 시 플랫폼→개발자→사용자 지시 우선순위(지시 계층)도 명문화됐다. OpenAI 스스로 현행 모델이 새 Spec을 완전히 반영하진 못한다고 밝혔고, 원칙을 내면화하는 새 학습법을 모색 중이라고 했다. Anthropic의 헌법적 AI와 같은 계보의 공개 가치 프레임워크 경쟁이다. Spec은 의도의 선언이고, 준수율은 별개 문제라는 점은 기억해야 한다.
