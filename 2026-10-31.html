MS Copilot 하네스, Foundry로 외부 공개
Microsoft (10월 28일) · Unite.AI · The New Stack

GitHub Copilot과 Copilot Studio를 굴리는 엔진, Microsoft Copilot 하네스가 Foundry Agent Service에서 공개 프리뷰로 외부에 열렸다. 하네스란 모델 주변의 모든 것. 지시문, 컨텍스트, 실행 환경, 통제 장치를 묶은 오케스트레이션 계층이다. GitHub 엔지니어들이 만들고 MS 전 제품에 표준화한 것으로, 20개 이상의 프론티어 모델과 MCP·에이전트 스킬·플러그인을 지원한다. 런타임은 Rust로 포팅해 세션 오버헤드와 첫 토큰 시간을 줄였다고 한다.

조건을 봐야 한다. 관리형 하네스는 생성 시에만 선택 가능하고, 나중에 바꿀 수 없다. 외부 모델 반입(BYOM)은 관리형에서는 미지원이고, 키 반입(BYOK)은 SDK 쪽에 있다. 기본 내장 도구는 파일 읽기·쓰기·셸·웹 fetch·서브에이전트 5종이다. 요금은 12월 1일부터 샌드박스 기준 vCPU 시간당 $0.0994, 메모리 GiB 시간당 $0.0118로, 1vCPU+1GiB를 한 달 내내 돌리면 약 $80 수준이다. 모델 추론비는 별도다. 긴 작업·장시간 복원력은 정식 출시됐다.

🔧 하네스 관점
네 하네스와 정반대 방향의 제품화다. 네 것은 .env 렌더링 + 듀얼 리뷰어라는 얇고 투명한 계약이고, MS 것은 샌드박스·정책·모델 라우팅까지 통째로 관리해 주는 두꺼운 런타임이다. 참고할 점은 세 가지다. 하네스 선택의 비가역성(생성 시 고정), 기본 도구 5종의 최소 집합, 그리고 "단순 작업엔 하네스가 오히려 지연·비용"이라는 MS 자체 권고. 네 리뷰어에도 "복잡도에 따라 하네스 강도를 달리한다"는 원칙으로 가져올 만하다.

볼 포인트 ─ 12월 1일 과금 후 실제 비용, BYOM 지원 여부, 국내 리전 포함 여부(현재 9개 지원 리전에 인도·동남아 없음).

학습 옵트아웃, 이제 한 줄이면 된다
OpenAI·Google·Microsoft·Anthropic (10월 30일) · The Verge · Google Search Central

4대 랩이 공통의 AI 학습 옵트아웃 신호를 받기로 했다. robots.txt에 User-Agent: __usage_ai-training + Disallow: / 두 줄이면, 참여 기업 전체에 학습 제외 의사를 한 번에 밝히는 셈이다. 지금까지는 GPTBot·Google-Extended·ClaudeBot 등 크롤러마다 따로 막아야 했다. 근거 문서는 Anthropic의 Kevin Kelley가 쓴 IETF 개인 초안 "Machine-Readable Training Preference Signal"(10월 30일, 만료 2027년 5월 3일)로, 아직 정식 표준이 아니고 자발적 신호다.

일정이 제각각이다. Anthropic은 이미 구현 시작, OpenAI는 "수개월 내", Microsoft는 2027년 2월 1일, Google은 2027년 목표다. 주의할 점도 많다. 학습만 막을 뿐 크롤링·검색·AI 답변 인용은 막지 못한다. 이미 수집·학습된 데이터는 소급 제거되지 않는다. 와일드카드 User-Agent: *는 정책 토큰과 매칭되지 않으며, 토큰이 없는 파일은 어떤 선호도 표명한 게 아니다. Microsoft는 학습과 별도로 AI Grounding 설정까지 추가했고, NoArchive·NoCache 사용자는 2027년 3월 1일까지 전환해야 한다.

국방망에 개인 Claude Code를 연결한 사건
WIRED (10월 30일) · Accenture 반박 포함

WIRED 보도에 따르면 Accenture 소속 계약직원이 미 국방부의 중앙 시스템을 개인 Claude Code 계정에 연결했다. 에이전트에 자신의 로그인 정보를 넘겨 관리자 권한을 얻게 하고, 보안 통제를 우회해 자동 코딩과 클라우드 서버 개설을 시켰다는 것이다. 에이전트는 국방망에서 약 2개월간 동작했고, 그 과정에서 로그인 정보·비밀번호와 NIPRNet(비기밀망) 네트워크 지도가 NIST 고위험 지정된 제3자 사이트로 전송된 것으로 보인다고 한다. 시스템에는 통제 비기밀정보(CUI)가 있었다.

양측 입장이 갈린다. Accenture는 "철저하고 독립적인 조사 결과 근거 없음"이라고 했고, 국방부는 "네트워크나 시스템 상태에 대해 언급하지 않는다"고 했다. 국방부 직원은 현재 Claude 사용이 금지된 상태라고 한다. 배경도 있다. Anthropic은 대규모 감시·완전 자율무기 용도 제한을 고수하다 국방부로부터 공급망 위험 기업 지정을 받았고, 법정 공방이 진행 중이다. 개인 계정 에이전트에 자격증명을 넘기는 행위가 조직의 통제 밖에서 어떻게 사고가 되는지 보여주는 사례다.

KT 토큰팩토리… 500종 모델을 한 API로
KT (10월 27일 공개, 10월 30일 출시) · 연합뉴스 · 한국경제

KT가 AI 모델 통합 플랫폼 '토큰팩토리'를 10월 30일 기업 고객 대상으로 출시했다. 모델 선택부터 가입·사용량 확인·비용 관리·결제까지 한곳에서 처리한다. 핵심은 자체 개발한 '오토 모델 라우터'로, 질문의 업무 유형·난이도·요구 품질·비용을 분석해 적합한 모델을 자동 선택한다. KT는 RouterArena 종합 1위를 주장한다. 한국어 특성을 반영한 프롬프트 압축으로 입력 토큰을 줄이고, 라우터와 압축을 함께 쓰면 토큰 최대 25% 절감이 가능하다고 한다.

규모를 정확히 봐야 한다. 출시 시점은 KT 데이터센터 직접 구동 7종 + 글로벌 66종 = 총 73종이고, OpenRouter와의 국내 첫 공식 파트너십을 통해 연말까지 500종 이상으로 확대한다는 계획이다. 내년 3월에는 개인 개발자·일반 이용자로 넓히고 구독형 요금제를 낸다고 한다. 과금은 통신 과금 방식을 응용한 토큰 상세기록(TDR)으로 부서·모델별 사용량을 나눠 보고, 국내 데이터센터 추론으로 데이터 주권 우려를 줄인다는 구상이다. 단, 토큰 절감률이 곧 요금 절감률은 아니다.
