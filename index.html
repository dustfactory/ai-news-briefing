구글, 'Harness²' 오픈소스… 모델은 얼리고 하네스만 고친다
MarkTechPost · AI Daily Post (10월 18일)

구글 Cloud AI Research가 에이전트 프레임워크 Harness²(v0.1.0)를 GitHub에 공개했다. 핵심은 모델 가중치를 전혀 건드리지 않고, 에이전트를 둘러싼 '하네스'만 배포 시점에 재작성해 성능을 올리는 방식이다.

시스템 프롬프트·가드레일·메모리·툴 가이던스·서브에이전트·스킬·스크립트·플러그인, 이렇게 8개 파일을 에이전트 스스로 고친다. 실험 결과 1회 refinement만으로 GLM-5 + OpenCode 조합이 WorkBuddy-Bench에서 64.2→75.7점으로 올랐다.

핵심 수치
하네스 구성 파일8개
WorkBuddy-Bench (1회 refinement)64.2 → 75.7
버전v0.1.0

에이전트 개선의 레버가 '더 큰 모델'에서 '더 좋은 스캐폴딩'으로 이동한다는 선언이다. Vertex 호출 비용에 막힌 팀에게 파인튜닝 없는 개선 경로는 현실적이다.

🔧 하네스 관점
이건 사실상 네 하네스 구조를 구글이 정당화한 셈이다. AGENTS.md(시스템 프롬프트)·듀얼 검수(서브에이전트)·render.py(스크립트)가 8개 파일 분해와 1:1로 매핑된다. 한 단계 더하면 '실행 이력으로 프롬프트/스크립트를 고치는 refinement pass'를 네 하네스에 넣을 수 있다. 단, 이들의 벤치는 verifiers가 없는 'open world' 전제라, 네 하네스처럼 검수 기준이 명확한 쪽이 오히려 refinement 품질을 높이기 쉽다.

딥시크 V4.1-Flash-1017… '마이너 업데이트'라는 코딩 괴물
머니투데이 · 이데일리 · 조선비즈 (10월 17~18일)

딥시크가 9월 V4.1-Flash의 체크포인트 업데이트를 공개했다. 552B MoE 백본(토큰당 16B 활성화), 가중치 MIT 라이선스, 컨텍스트 100만 토큰.

자사 평가 기준 Terminal-Bench 4.0이 31.2→42.3(+36%), DeepSWE v1.1이 74.2→77.0으로 11개 벤치 전부 상승했다. API 가격은 그대로(`deepseek-flash` 이름으로 자동 교체) — OpenRouter 기준 입력 $0.15/출력 $0.60 per 1M, GPT-5.6 Sol($20)·클로드 오퍼스 5($25)의 33~42분의 1 수준이다.

핵심 수치
파라미터552B MoE (활성 16B)
Terminal-Bench 4.031.2 → 42.3
API (입력/출력, per 1M)$0.15 / $0.60

가격 파괴보다 진짜는 '하네스 최적화'다. 딥시크는 이 모델이 자사 DeepSeek Harness·텐센트 CodeBuddy·WorkBuddy에 최적화됐다고 못 박았다. 모델 경쟁이 하네스 경쟁으로 번지는 증거다. 출력 길이를 줄여 코딩 작업당 비용을 $0.5→$0.2로 60% 낮췄다는 점이 진짜 인사이트 — 에이전트 비용의 적은 토큰 단가가 아니라 '얼마나 길게 쓰는가'다.

다만 벤치표에 Opus 5.5·GPT-6.1 Sol이 빠져 있고(구세대인 Opus 5·GPT-5.6 Sol과만 비교), X의 Thomas Wolf·Nathan Lambert도 '자사 평가 밖에서 유지될지 의문'이라 했으니 'Opus 5급' 주장은 할인하고 봐야 한다.

볼 포인트 ─ 독립 벤치 검증, 10/31 무료 종료 후 가격 정책.

엔비디아 Nemotron 3.5… GPU 회사가 모델·학습법까지 푼다
솔루션뉴스 (10월 17일 — 10월 15일 공개)

엔비디아가 기업용 AI 에이전트 겨냥 오픈 모델 2종을 공개했다. '슈퍼 VL'(120B 중 12B만 활성화하는 MoE, 비전+언어 멀티모달)과 로컬용 '볼트 74B-A9B'(74B 모델을 24GB VRAM에 넣어 RTX 노트북에서 클라우드 없이 에이전트 구동). 가중치·데이터·학습법을 전부 공개하고 상업 이용도 허용한다.

핵심 주장은 "기업이 자기 데이터로 추가 학습하면 특정 업무에서 클로드·GPT를 넘는다" — 의료보험 청구 심사 정확도가 28%→72%(클로드 오퍼스 5는 38%), 보안 대응 과제가 35%→76%(GPT-6.1 솔 66%)였다고. 단, 과제 정의·표본 수·시험 방법은 비공개다.

칩 회사가 모델→개발도구→실행환경까지 수직 통합으로 경쟁 영역을 넓히고 있다. '폐쇄형 API vs 오픈 가중치+파인튜닝' 구도가 엔터프라이즈 에이전트 시장의 주전선이 되는 모양이다.

🔧 하네스 관점
Bolt처럼 24GB급 로컬 모델이 에이전트용으로 나온다는 건, 서브에이전트/검수 같은 저비용 역할에 로컬 모델을 붙이는 아키텍처가 현실권에 들어왔다는 뜻이다. 네 하네스의 검수 역할도 비용 구조를 다시 짜볼 여지가 있다.

앤트로픽, KBRA BB+ 등급… 600억弗 조달 추진
SignalPlus (10월 16일)

앤트로픽이 신용평가사 KBRA로부터 투자적격 바로 아래인 BB+ 등급을 받았다. 월스트리트 은행들이 구글·브로드컴 칩 개발과 연계된 600억 달러 규모 자금조달 패키지를 주선 중이고, 칩 리스를 위한 전환사채를 최대 420억 달러까지 발행할 수 있다는 보도다. 밸류에이션 9,650억 달러 보도도 있으나 단일 소스라 확인 필요.

AI 랩들이 이제 '칩을 사는' 게 아니라 '전력을 몇 GW 단위로 계약하고, 칩 회사가 자기 대차대조표로 돈을 대주는' 구조로 들어갔다. 엔비디아-OpenAI 1000억 달러 LOI, 브로드컴-앤트로픽 420억 달러 리스 지원이 같은 패턴이다.

FII 보고서 기준 2026년 글로벌 AI 지출 4,000억 달러, 기업의 88%가 AI 사용 중이지만 73%는 보안을 최대 과제로 꼽았다. 인프라 돈은 계속 풀리는데, 수익성 증명(딥시크 쇼크 2라운드 우려 — 나스닥 10/16 -2.1%)이 변수다. 삼성전자·SK하이닉스도 이번 주 주가 변수로 거론된다. '제번스의 역설'(싸지면 더 쓴다) vs '투자 수익성 의문' 구도가 이번 주 시장의 핵심 축이다.
