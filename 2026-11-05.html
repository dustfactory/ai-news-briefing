OpenAI, Pierre 인수… 에이전트의 Git을 통째로 쥐다
Axios (11월 4일) · SiliconANGLE · The Neuron

OpenAI가 11월 4일 개발자 도구 스타트업 Pierre Computer 인수를 발표했다. 이틀 전 공개한 내부 Git 백엔드 Pando에 이은, 같은 문제의 바깥쪽 해법이다. Pierre는 2023년 YC 겨울 배치 출신으로, Git 기반 분산 코드 스토리지 서비스 'Code Storage'와 오픈소스 라이브러리 Trees·Diffs를 만든다. Trees와 Diffs는 이미 Codex 앱 안에서 파일 탐색과 변경 렌더링을 담당하고 있다. 즉 Codex에서 프로젝트를 둘러보고 리뷰를 읽는 그 화면 자체가 Pierre 제품이었다는 뜻이다.

Code Storage는 사람을 위한 호스팅이 아니라 기계를 위한 Git 인프라다. 앱이 에이전트용 저장소를 프로그래밍 방식으로 만들고, 푸시·클론·가져오기를 API로 다루며, GitHub·GitLab·Bitbucket과 동기화한다. 2025년 10월 출시 당시 내세운 방향이 "AI가 만든 코드의 임시 브랜치와 재현 가능한 스냅샷"이었고, Lovable·Bolt·Amp·Poke 같은 AI 코딩 서비스가 고객이라고 한다. 인수가는 비공개, 규제 승인이 남아 있어 종결 전까지 양사는 별개로 운영되고, 기존 Code Storage 고객은 계속 이용할 수 있으며 오픈소스는 유지된다고 한다.

인수 발표11월 4일

종결 조건규제 승인 대기

왜 중요한가. 에이전트가 코드를 대량으로 쓰기 시작하면 병목은 생성 속도가 아니라 "읽고, 머지하고, 저장하는" 쪽으로 이동한다. OpenAI는 Pando로 내부 모노레포의 병목을, Pierre로 외부 머신용 저장소를 각각 쥐는 그림이 됐다. 다만 "GitHub에 대한 도전"이라는 프레임은 Axios의 해석이고, OpenAI 발표 자체는 GitHub 대체가 아니라 에이전트용 Git 워크플로 적응에 방점을 찍었다. 두 회사가 Pando와 Pierre를 하나의 공개 서비스로 합친다고 밝힌 바도 없다. 이 구분을 흐리면 안 된다.

🔧 하네스 관점
네 하네스의 규칙 14(UI를 직접 조작하고 전후 이미지를 남긴다)는 리뷰 증거의 표면을 중시한다. 그 리뷰 표면(Trees·Diffs)과 저장소(Code Storage)가 한 회사 손에 들어가면, 리뷰 렌더링의 중립성과 재현 기준을 하네스 쪽에서 명시해 둘 이유가 커진다. 또 "검수 에이전트는 읽기 전용, 쓰기는 한 경로로"라는 원칙과 Code Storage의 머신용 쓰기 API는 정반대 방향이라, 하네스에 '리뷰어는 저장소에 쓰지 않는다'는 경계를 AGENTS.md에 못 박아 두는 편이 안전하다.

볼 포인트 ─ 규제 승인 시기, Code Storage의 Codex 통합 가격·한도, Pando와 Pierre의 실제 통합 여부.

텐센트 Hy4… API로는 열렸고, 가중치는 아직 닫혔다
텐센트 Hy 팀 (11월 4일) · Reuters · Unite.AI

텐센트 Hy 팀이 11월 4일 플래그십 모델 Hy4 정식판을 내놨다. 8월 28일 프리뷰의 후속으로, 프리뷰 스펙 기준 770B 파라미터 MoE에 활성 49B, 컨텍스트 100만 토큰이다. 이번 정식판의 두 가지 처음은 비전 이해와 컴퓨터 사용이다. 텐센트 클라우드 TokenHub와 WorkBuddy·CodeBuddy, Yuanbao, ima, 위챗 워크 Dayuan, 그리고 OpenRouter·Hermes·OpenCode API로 쓸 수 있다. 가격은 프리뷰와 같은 입력 100만 토큰당 6위안(약 0.834달러), 출력 18위안(약 2.501달러)이며, TokenHub는 12월 31일까지 50% 할인, WorkBuddy·CodeBuddy는 11월 4~15일 무료다. 더 빠르고 싼 Hy4 Flash도 예고됐으나 일정은 없다.

가장 큰 반전은 '오픈'이라는 말의 범위다. 프리뷰는 출시와 함께 오픈소스였는데, 정식판 가중치는 "공개 계획"만 있고 날짜가 없다. 허깅페이스에는 프리뷰 저장소만 있고, OpenRouter의 가중치 버튼도 공개 접근이 안 되는 링크로 연결된다고 한다. 시스템 카드도 가중치 공개 시점에 함께 나온다고 한다. 안전 쪽에서는 방어용 사이버보안 훈련만 허용하고 해킹 도구 제작·침투 테스트 자료를 제외했으며, 내부 테스트에서 생물 위험 실험을 의미 있게 쉽게 만들지 못했다고 밝혔다(Reuters). API로는 당장 써볼 수 있지만, 가중치를 직접 돌리고 싶다면 아직 기다려야 하는 상태다.

Axion 1.0… 1만 8천 개 예제로 만든 오픈 에이전트 모델
arXiv 2611.03233 (11월 2일) · ByteDance Axion 팀

바이트댄스·듀크대·메릴랜드대·버팔로대 팀이 11월 2일 'Axion 1.0: Open Agent Foundation Models, Simplified'를 공개했다. 요지는 단순하다. 복잡한 파이프라인이 아니라 데이터 품질과 과제 구성이 중요하다는 것이다. 레시피는 3단계뿐이다. 지도 미세조정(SFT) 2회와 비동기 강화학습(RL) 1회, 훈련 궤적은 18,363개다. 122B 변형 기준 약 1,000 GPU-시간이라는 2차 정리도 있는데, 다른 2차 정리 제목에는 90 GPU-시간이라고 적혀 있어 이 수치는 확인 필요하다. 모델은 35B(활성 3B)와 122B(활성 10B) MoE로, 베이스는 Qwen3.6-35B-A3B와 Qwen3.5-122B-A10B, SFT 단계 컨텍스트는 128K다.

성적은 연구 에이전트 특화다. 122B는 Humanity's Last Exam 59.0(제한적 웹 접근 조건), FrontierScience 올림피아드 87.0·리서치 66.7, 35B는 SEAL-0 62.2로 비교표에서 가장 높았다고 한다. 공개 범위에는 주의가 필요하다. 데이터 구축·필터링 코드, 프롬프트, 훈련 코드, 평가·채점 스크립트는 Apache 2.0으로 열려 있지만, 35B 체크포인트는 프로젝트 README 스스로 "커뮤니티 재현본이지 공식 체크포인트가 아니다"라고 밝히고 있고, 122B 가중치 링크는 확인된 출처에서 찾지 못했다. 35B BF16도 약 70GB라 로컬 실행이 가볍지 않다. '완전 오픈'이라는 말은 레시피 공개에는 맞고, 가중치 즉시 실행에는 아직 아니다.

🔧 하네스 관점
Axion의 진짜 자산은 점수가 아니라 "데이터 구축부터 평가·채점 스크립트까지 통째로 공개"한 점이다. 네 하네스도 AGENTS.md 규칙과 검수 역할뿐 아니라, 고정 평가셋과 채점 기준을 같은 급으로 남기면 재현·비교가 된다. 네가 Laya 평가에 쓰던 12커밋 고정 셋이 바로 그 패턴이다. 또 18K 고품질 예제로 큰 모델과 겨루는 교훈은, 평가셋을 크게 만드는 것보다 "어떤 실패를 재는가"를 먼저 정하는 게 중요하다는 뜻이다.

볼 포인트 ─ 122B 공식 가중치 공개 여부, 35B 재현본의 독립 재현 결과, GPU-시간 수치 정정 여부.

AMD·퓨리오사·망고부스트… 국산 NPU를 AMD 생태계에
AMD Advancing AI 서울 2026 (11월 4일) · 조선비즈 · 전자신문

AMD가 11월 4일 'AMD 어드밴싱 AI 서울 2026'에서 퓨리오사AI, 망고부스트와 개방형 이기종 AI 인프라 MOU를 맺었다. 조합은 이렇게 나뉜다. AMD EPYC CPU와 Instinct GPU, 퓨리오사AI 2세대 NPU '레니게이드(RNGD)', 망고부스트 DPU와 소프트웨어다. 목표는 추론 워크로드의 특성에 따라 컴퓨팅 자원을 배분하는 인프라를 공동 설계·검증하는 것이고, 망고부스트가 서울에서 운영하는 인프라를 활용한 참조 시스템을 2027년 중 가동을 목표로 구축한다. 일부 보도에는 2027년 봄 가동 목표라고도 나와 있다. 배경은 지난 7월 과기정통부와 AMD의 전략적 파트너십 연장선이고, AMD는 10월 수백 명 규모 국내 AI 연구센터 설립 계획도 밝힌 바 있다.

의미는 엔비디아의 폐쇄 스택에 대한 개방형 대안이다. CPU는 작업 조율, GPU는 대규모 연산, NPU는 저전력 추론과 토큰 처리 가속, DPU는 네트워크·메모리 병목 해소로 역할을 나눈다. 추론 비용 구조가 "GPU 한 종류"에서 "워크로드별 최적 칩 조합"으로 갈라지면, 추론 인프라를 고를 때 칩 조합 자체가 비용 변수가 된다. 한국 NPU가 AMD 글로벌 생태계에 편입되는 첫 사례라는 점에서, 국내 추론 인프라 선택지가 넓어지는 효과도 있다. 다만 MOU 단계라, 참조 시스템의 실측(토큰 처리량·전력·총소유비용)이 나오기 전에는 구호와 실행을 구분해야 한다.

볼 포인트 ─ 2027년 참조 시스템 실측 공개 여부, RNGD 양산·공급 일정, 과기정통부 후속 지원과 AMD 국내 연구센터 채용 진척.
